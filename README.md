# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

This assignment practices Python functions, parameters, return values, and default parameters.

## Files

* `welcome.py` - Contains a welcome function that creates greetings for different names.
* `toolbox.py` - Contains functions for doubling numbers, checking passing scores, and creating greetings.

## Hardest Function

The `greet` function was the hardest to write because it uses a default parameter. I had to understand how Python uses `"Hello"` automatically when no greeting is provided.
